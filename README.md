# Proposal.html

A charming interactive "will you be my girlfriend?" webpage.

## Preview

Open [index.html](index.html) in your browser to view the page.

## What it includes

- A romantic animated card UI
- Heart particle effects
- Interactive yes/no prompts
- A playful final celebration screen

## Run locally

1. Open [index.html](index.html) in any modern browser.
2. Click the buttons or tap the hearts to interact.
